# GUI Applications

This directory contains Python-based graphical user interface (GUI) applications built using Tkinter and other GUI frameworks.

Each project is maintained in its own directory, with dedicated source code, documentation, and dependencies where required.

## Projects

- **DB Manager:** A lightweight SQLite database management application built using Python and Tkinter.

## Technologies

- Python
- Tkinter and ttk
- SQLite
- Other GUI libraries as required
- Others

## Purpose

This directory serves as a collection of desktop application projects developed to explore GUI programming, application design, database integration, and software development practices.
