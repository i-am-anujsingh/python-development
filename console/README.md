# Console-Based Applications

This directory contains Python-based console applications and command-line programs developed to practise programming concepts, implement problem-solving approaches, and build functional utilities.

Each project is maintained in its own directory, with dedicated source code, documentation, and dependencies where required.

## Projects

- **ATM Simulation:** A console-based ATM application that simulates basic banking operations.
- **Other Projects:** Additional console-based programs and utilities will be added as development progresses.

## Technologies

- Python
- Standard Python Libraries
- Object-Oriented Programming (OOP)
- File Handling
- Exception Handling
- Data Structures and Algorithms (DSA)
- Other libraries as required

## Purpose

This directory serves as a collection of console-based projects developed to strengthen Python programming fundamentals, explore problem-solving techniques, practise software development concepts, and build command-line utilities.
